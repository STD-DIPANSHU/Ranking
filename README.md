# 🤖 ChatFight-Style Telegram Stats Bot

A Telegram bot that tracks group activity and shows **daily, weekly, and all-time leaderboards**  
with a **ChatFight-style red glowing theme** 🔥  

---

## 🧠 Features

- Counts messages in groups
- `/top today` → Today’s leaderboard  
- `/top week` → Weekly leaderboard  
- `/top all` → All-time leaderboard  
- `/mystats` → View your personal stats  
- Generates **red glowing leaderboard images** like ChatFight
- Fully deployable on **Heroku + MongoDB Atlas**

## ⚙️ Environment Variables

| Name | Required | Description |
|------|-----------|-------------|
| `BOT_TOKEN` | ✅ | Telegram bot token from [@BotFather](https://t.me/BotFather) |
| `MONGO_URL` | ✅ | MongoDB connection string (e.g. from [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)) |
